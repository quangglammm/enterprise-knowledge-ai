# Engineering On-call Runbook

## Escalation

The primary on-call engineer must acknowledge a page within 15 minutes. If a page is not acknowledged within 15 minutes, it escalates to the secondary on-call engineer. If it is still not acknowledged after 30 minutes, the engineering manager is paged.

## Handover

On-call handover happens every Monday at 09:00 local time. The outgoing engineer writes a handover note listing open incidents and follow-up tasks.

## Incident channel

For every SEV1 incident, the primary on-call engineer opens a dedicated chat channel named inc-YYYYMMDD and posts status updates every 30 minutes.
