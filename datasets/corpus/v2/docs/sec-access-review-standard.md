# Access Review Standard

Restricted to the security team.

## Scope

This standard covers access to production systems, the HR system, finance systems and the customer database.

## Review frequency

Access to every system in scope is reviewed every quarter by the system owner. Privileged access, including administrator and database superuser roles, is reviewed every month by the security team.

## Leavers and movers

When an employee leaves, HR notifies the IT service desk on the last working day, and all accounts must be disabled within 4 hours. When an employee changes role, access that is no longer needed is removed within 5 working days.

## Evidence

Each review is recorded with the reviewer's name, the date and the list of removed accounts. Records are kept for 2 years for audit.
