# Vendor Security Requirements

For managers and the security team.

## Risk assessment

Every vendor that processes Bamboo Harbor data completes a security questionnaire before the contract is signed. The assessment is repeated every year for vendors that handle Confidential or Restricted data.

## Certification

Vendors that process Restricted data must hold a current SOC 2 Type II report or ISO/IEC 27001 certification. Vendors without one may be approved only by the Chief Information Security Officer, with a remediation plan.

## Contract terms

Contracts must require the vendor to report a security incident affecting Bamboo Harbor data within 24 hours and to delete or return all data within 30 days after the contract ends.
